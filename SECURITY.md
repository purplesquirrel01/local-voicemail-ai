# Security policy

Report suspected vulnerabilities privately through the repository's GitHub
Security Advisory page. Do not post credentials, private data, production
transcripts, recordings, or exploit details in public issues.

Include the source revision, affected component, impact, and synthetic
reproduction steps. This is a portfolio/reference implementation with no promised
production support or certified release channel.

The software makes no HIPAA compliance or certification claim.
See [security design and limits](docs/SECURITY_AND_PHI.md).
